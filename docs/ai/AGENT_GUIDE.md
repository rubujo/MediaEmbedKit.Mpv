# 共用 AI Agent 指南

此檔案只保留舊路徑相容索引。新的跨 CLI 主要入口是根目錄 `AGENTS.md`。

## 使用順序

1. 先閱讀 `AGENTS.md`。
2. 依任務閱讀 `docs/PROJECT_SPEC.md` 索引的專責文件。
3. 編修本專案時使用 `docs/ai/skills/mediaembedkit-mpv.md`。
4. 追蹤 shinchiro/zhongfly mpv git build 或比對 libmpv header 時使用 `docs/ai/skills/libmpv-git-build-tracker.md`。

不要在本檔新增專案規則；請改更新 `AGENTS.md`、`docs/PROJECT_SPEC.md`、專責文件或共用 skill。
